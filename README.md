CompetitorMap

“Finding competitors is easy when everyone sells the same obvious thing. It gets more interesting when the real alternative is a spreadsheet, WhatsApp, an internal team, an agency, or a workflow that has survived for twelve years for reasons nobody can explain.

CompetitorMap takes a company’s website and maps the market around it. It identifies direct competitors, adjacent products, and alternative ways customers might solve the same problem, then explains why each one belongs on the map.

The output can include competitive categories, similarity, positioning, target market, publicly available pricing, and a ranked list of relevant companies or alternatives. The goal is context rather than a giant list of company names.

The intended workflow combines company-information extraction, web research, candidate discovery, website analysis, semantic comparison, ranking, and structured AI analysis.

Built with Next.js, TypeScript, and Tailwind CSS, with research and web-analysis capabilities added as the project develops.

Sometimes your biggest competitor is a company. Sometimes it is an Excel spreadsheet that everyone is weirdly attached to.”
